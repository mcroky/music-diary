# 로키의 음악일기

소리로 쓰는 나의 하루. [음악일기 열기](https://mcroky.github.io/music-diary/) · [Roky Studio](https://mcroky.github.io/roky-studio/)

- 16개 콘셉트의 합성 음악 64곡과 환경음·악기 믹서
- 날짜별 음표 보상과 새 방·팝 음악을 여는 상점
- 하루와 월간 앨범의 MP3·WAV 저장: 다운로드당 음표 1개
- 다섯 기본 방과 온실 방, 조명·날씨·시간 선택
- 로컬 일기·초안·음표·구매 내역과 JSON 백업
- 한국어·영어·일본어·중국어

## 개인정보와 저장

계정·서버 데이터베이스·분석 도구 없이 일기와 음표 내역을 기기에 보관합니다. 브라우저 데이터를 지우기 전 JSON 백업을 저장하세요. 초안은 일기로 저장해야 백업에 포함됩니다. 외부 링크와 사용자가 선택한 클라우드 저장 위치에는 해당 서비스의 정책이 적용됩니다.

음악은 Web Audio로 합성합니다. MP3 인코더 출처와 라이선스는 [안내](assets/vendor/mp3/NOTICE.txt)에 있습니다. 현재 버전은 0.11.0입니다.
