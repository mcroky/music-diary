# 로키의 음악일기

소리로 쓰는 나의 하루. 오늘의 감정을 음악과 작은 방으로 남겨요.

[음악일기 열기](https://mcroky.github.io/music-diary/) · [Roky Studio](https://mcroky.github.io/roky-studio/)

- 12개 콘셉트의 오리지널 합성 음악 48곡과 환경음·악기 믹서
- 네 가지 원클릭 편곡과 멜로디 악기·리듬·음악의 여백 조절
- 월별 음악 앨범, 날짜순 이어 듣기와 MP3·WAV 파일 저장
- 다섯 방, 조명·날씨·시간, 몰입 감상
- 로컬 일기·자동 초안 저장·달력·JSON 백업과 가져오기
- 한국어·영어·일본어·중국어

## 개인정보와 저장

계정·서버 데이터베이스·분석 도구를 사용하지 않습니다. 일기와 초안은 이 주소를 연 브라우저에 저장됩니다. 다른 기기·브라우저·주소와 자동 동기화되지 않습니다. 브라우저 데이터를 지우면 기록이 사라질 수 있으므로 정식 저장한 일기를 JSON 파일로 백업하세요. 초안은 먼저 일기로 저장해야 파일 백업에 포함됩니다. 외부 링크를 열면 해당 서비스의 정책이 적용됩니다.

음악은 Web Audio로 합성합니다. 재생 버튼을 눌러 시작하며 화면이 숨겨지면 멈춥니다. 백그라운드·잠금 화면 재생과 Android 앱 출시는 지원하지 않습니다. 방 그림은 AI로 제작한 오리지널 이미지입니다.

## 배포

이 저장소에는 공개 웹 실행 파일만 포함합니다. 별도 빌드 없이 main 루트에서 GitHub Pages로 배포합니다. MP3 인코더와 라이선스 안내는 [여기](assets/vendor/mp3/NOTICE.txt)에서 확인할 수 있습니다. 현재 버전은 0.9.0이며 사용자 주소는 버전과 관계없이 고정합니다.
